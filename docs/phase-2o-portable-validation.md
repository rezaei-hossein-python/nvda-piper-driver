# Phase 2O portable validation

Compare the accepted Phase 2L package with the opt-in held-loop package in
separate disposable configurations. Test slow and rapid typing, repeated
characters, held keys for 2, 5, and 15 seconds, release latency, different-key
interruption, Alt+Tab, navigation, mouse-over, cancellation, Read All,
edit-box recovery, eSpeak switching, and shutdown.

The acceptance question is whether feedback remains continuous without a
backlog while preserving natural selected-voice character audio. Internal
feed timestamps are not physical audible-onset measurements.
