# Phase 2M portable validation

Compare the accepted Phase 2L Package C against a length-scale package in
separate disposable configurations. Test repeated and held characters, mixed
typing, punctuation, Unicode, navigation, mouse-over, edit-box recovery,
Read All, cancellation, eSpeak switching, and shutdown. Evaluate clarity,
voice identity, naturalness, backlog after release, and perceived speed.
Physical audible onset is not claimed without synchronized loopback capture.
