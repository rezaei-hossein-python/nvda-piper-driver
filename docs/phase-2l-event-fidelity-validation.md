# Phase 2L event-fidelity validation

Package A is the current cache baseline. Package B is the event-fidelity
experiment with the bounded character FIFO. Use separate disposable configs,
hold and repeat identical characters, then test mixed typing, navigation,
mouse-over, edit-box recovery, Read All, cancellation, eSpeak switching, and
shutdown. Acceptance requires user confirmation that repeated events improve
without navigation or regression harm.
