# Phase 2M held-key validation

Compare the accepted Phase 2L package with the held-key experiment in separate
portable configurations. Test slow repeated typing, a several-second held
key, rapid mixed typing, navigation and focus interruption, mouse-over,
cancellation, Read All, edit-box recovery, synthesizer switching, and clean
shutdown.

The rejected length-scale experiment is not enabled in the held-key package.
Use only the explicit held-key package marker. Reports must include accepted,
aggregated, dropped, and completed event counts without speech text.
