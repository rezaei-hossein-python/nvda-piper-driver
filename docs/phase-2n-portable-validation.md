# Phase 2N portable validation

Compare the accepted Phase 2L package with at most two acceleration factors in
separate disposable configurations. Test normal and repeated characters,
held-key release, mixed typing, punctuation, Unicode, navigation, mouse-over,
edit-box recovery, document reading, Read All, cancellation, eSpeak switching,
and shutdown.

Rate each candidate for speed, clarity, naturalness, voice identity, fatigue,
and backlog. Do not accept a factor from internal duration measurements alone.
